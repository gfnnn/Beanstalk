Self-hosted web fonts for beansprout.ink
========================================

The "latin" subset of each family, as served by Google Fonts (fetched 2026-11-18),
unmodified. Declared in apps/web/src/styles/fonts.css.

  fraunces-latin.woff2          Fraunces (roman), variable: optical size + weight   — v38
  fraunces-italic-latin.woff2   Fraunces (italic), variable: optical size + weight  — v38
  karla-latin.woff2             Karla (roman), variable: weight                     — v33
  jetbrains-mono-latin.woff2    JetBrains Mono (roman), variable: weight            — v24
